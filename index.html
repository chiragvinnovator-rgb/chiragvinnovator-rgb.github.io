How I solve problems

From a business question to a better way of working.

The same five steps run through every project here, whatever the tools.

  1. Understand

    Start with the business question

    Who owns the problem, what decision depends on it, and what a useful answer would change.

  2. Map

    Follow the process

    Trace the work from start to finish to see where it waits, loops back or depends on memory.

  3. Analyse

    Test the evidence

    Use data, statistics and models to separate real causes from coincidence.

  4. Design

    Choose the solution

    Compare options against the constraints, and recommend the one that holds up.

  5. Improve

    Run it and measure it

    Define how the change will be operated and measured, so the result can be checked.
